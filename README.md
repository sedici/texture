# OJS Texture Plugin

Integrates the [Texture](https://github.com/substance/texture) editor with OJS workflow for direct editing of [JATS XML](https://jats.nlm.nih.gov/archiving/1.1/) documents.

## SEDICI fork (OJS 3.5)

This branch is based on PKP's `stable-3_5_0` and adds the changes used by SEDICI/SUMARC:

* **References editor:** additional fields and reference types in `texture/texture.js` (translators, compilers, institutional authors, comment, URI/URL, report number, issue for magazine and newspaper articles, thesis publication number/degree/awarding institution, conference type of presentation, among others).
* **Edit with Texture in every workflow stage:** the action is offered for XML files in the submission, review, draft, copyedited and production ready file lists (PKP's version only offers it in Production Ready). The editor checks access against the workflow stage of the list it was opened from. This is needed to edit the XML generated by the `docxConverter` plugin in the copyediting stage.
* **Images in the editor:** the `texture/media` operation is implemented (images were not displayed otherwise) and images are matched with their dependent files by file name.
* **Image upload from the editor:** the image genre is looked up among all enabled genres, and the file name is stored with the journal's submission locales.

Branches for other versions: `dev-3_4` / `stable-3_4_0` (OJS 3.4) and `dev-3_3` / `stable-3_3_0` (OJS 3.3).

## Installation

```bash
cd $OJS
git clone -b dev-3_5 https://github.com/sedici/texture.git plugins/generic/texture
cd plugins/generic/texture
npm install
npm run build
cd $OJS
php lib/pkp/tools/installPluginVersion.php plugins/generic/texture/version.xml
```

Activate in *Settings > Website > Plugins*.

## Usage

1. Upload a JATS XML file to any file list of the workflow (for example `Copyedited` or `Production Ready`), or convert a DOCX file with the `docxConverter` plugin ([blank manuscript](https://github.com/substance/texture/tree/master/data/blank) | [samples](https://github.com/substance/texture/tree/master/data/))
2. Choose `Edit with Texture` in the `⋯` menu of the XML file
3. Uploaded images are integrated as dependent files of the XML file
4. When publishing as galley, re-upload images in the dependency grid

## Supported JATS Tags

**Supported:** `code`, `disp-formula`, `disp-quote`, `fig`, `fig-group`, `graphic`, `list`, `p`, `preformat`, `sec`, `supplementary-material`, `table-wrap`, `tex-math`

**Not yet supported:** `ack`, `address`, `alternatives`, `array`, `boxed-text`, `chem-struct-wrap`, `def-list`, `disp-formula-group`, `media`, `related-article`, `related-object`, `sig-block`, `speech`, `statement`, `table-wrap-group`, `verse-group`, `x`

## API Endpoints

All endpoints require parameters: `submissionId` (int), `fileId` (int), `stageId` (int).

| Method | Endpoint | Description | Extra Params |
|--------|----------|-------------|--------------|
| GET | `/texture/json` | Get DAR file (JSON) | -- |
| PUT | `/texture/json` | Update DAR file | Payload: DAR file |
| GET | `/texture/media` | Get media file | `assocId` (XML submission file id), `fileId` (int) |
| DELETE | `/texture/media` | Delete media file | -- |
